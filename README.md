# 📌 Real-Time Face Detection using OpenCV

## 🧠 Project Overview
This project implements a **Real-Time Face Detection System** using Python and OpenCV. It detects human faces from live webcam input as well as static images by applying pre-trained classifiers.

The system identifies faces and highlights them with bounding boxes, demonstrating the fundamentals of Computer Vision and Image Processing.

---

## 🚀 Features
- Real-time face detection using webcam  
- Detect faces from images  
- Uses Haar Cascade Classifier  
- Fast and efficient detection  
- Beginner-friendly implementation  

---

## 🛠️ Technologies Used
- Python  
- OpenCV  
- NumPy  

---

## ⚙️ How It Works
1. Capture input from webcam or image  
2. Convert the image to grayscale  
3. Apply Haar Cascade classifier for detection  
4. Detect facial regions  
5. Draw rectangles around detected faces  
6. Display the output in real-time

## 🧪 Installation & Setup

### Step 2: Install dependencies
pip install opencv-python numpy  

### Step 3: Run the project
